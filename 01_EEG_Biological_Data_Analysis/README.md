# EEG Biological Data Analysis

## Overview
This portfolio project is inspired by my undergraduate EEG dissertation experience. The dataset used in this portfolio version is simulated and does not contain identifiable participant information.

## Research Question
How do alpha and beta EEG power differ between a resting condition and an active task condition?

## Workflow
1. Import and inspect EEG summary data.
2. Check the dataset for missing values and data-quality issues.
3. Calculate changes in alpha and beta power between conditions.
4. Perform paired statistical comparisons.
5. Visualise the differences between rest and task conditions.
6. Export the analysis results.
