# Machine Learning for Disease Classification

## Overview
This project is a machine-learning portfolio project using a simulated biomedical dataset. It demonstrates how supervised machine-learning methods can be applied to biological and healthcare data.

## Research Question
Can simulated demographic and biomarker features be used to classify disease status?

## Machine-Learning Models
- Logistic Regression
- Random Forest

## Workflow
1. Import and inspect the biomedical dataset.
2. Separate predictor variables from disease status.
3. Split the data into training and test datasets.
4. Standardise features where appropriate.
5. Train Logistic Regression and Random Forest models.
6. Generate predictions on unseen test data.
7. Evaluate and compare model performance.
8. Investigate feature importance.

## Model Evaluation
The models are evaluated using:
- Accuracy
- Precision
- Recall
- F1 score
- ROC-AUC

## Healthcare Relevance
Machine learning can support the analysis of complex biological and healthcare datasets, including disease classification, biomarker discovery and patient stratification.

## Portfolio Data
The dataset used in this project is simulated for educational and portfolio purposes. It does not contain real patient or participant information.

## Limitations
The results from this project should not be interpreted as evidence of clinical performance. A real healthcare machine-learning model would require appropriate clinical datasets, external validation, bias assessment and careful evaluation before clinical use.
