# Transcriptomics / Gene Expression Analysis

## Overview
This project is a bioinformatics learning project using a simulated gene-expression dataset. It demonstrates how computational methods can be used to explore differences in gene expression between two biological conditions.

## Research Question
Which genes show the largest differences in expression between a simulated control condition and disease condition?

## Workflow
1. Import and inspect gene-expression data.
2. Check the dataset for missing values and data-quality issues.
3. Calculate fold change between control and disease conditions.
4. Calculate log2 fold change.
5. Identify genes showing large expression changes.
6. Rank genes according to the magnitude of expression change.
7. Generate scientific visualisations.
8. Export the analysed results.

## Bioinformatics Relevance
Gene-expression analysis is an important area of transcriptomics and can help researchers investigate biological differences between conditions, identify potential biomarkers and better understand disease mechanisms.

## Portfolio Data
The dataset used in this project is simulated for educational and portfolio purposes. It does not contain real patient or participant data.

## Limitations
This is a simplified educational gene-expression workflow rather than a complete RNA-sequencing differential-expression pipeline. Future development of this project could include analysis of publicly available RNA-seq data and the use of established differential-expression tools.
