# Rhoda Adesina Iwendi | Bioinformatics Portfolio

## About Me

I am a Biomedical Science graduate preparing to begin an MSc in Bioinformatics at the University of Leicester.

My interests include bioinformatics, multi-omics, artificial intelligence, machine learning and the application of computational approaches to biological and healthcare data.

My undergraduate EEG research introduced me to computational biological data analysis using Python and RStudio and strengthened my interest in combining biology, data science and healthcare.

This portfolio documents projects I have developed to strengthen my practical skills in bioinformatics, biological data analysis and machine learning.

---

## 🧬 Portfolio Projects

### 1. EEG Biological Data Analysis

A biological data-analysis project inspired by my undergraduate EEG research.

The project demonstrates:
- Python-based biological data analysis
- Data cleaning and quality checking
- Statistical analysis
- EEG alpha and beta power comparison
- Scientific visualisation
- Reproducible analysis

➡️ [View EEG Project](./01_EEG_Biological_Data_Analysis)

---

### 2. Transcriptomics & Gene Expression Analysis

A bioinformatics learning project investigating simulated gene-expression differences between control and disease conditions.

The project demonstrates:
- Gene-expression data analysis
- Fold-change calculations
- log2 fold-change analysis
- Identification and ranking of expression changes
- Python, pandas and NumPy
- Scientific visualisation

➡️ [View Transcriptomics Project](./02_Transcriptomics_Gene_Expression)

---

### 3. Machine Learning for Disease Classification

A machine-learning project exploring whether simulated biomedical features can be used to classify disease status.

The project demonstrates:
- Machine-learning workflow development
- Logistic Regression
- Random Forest
- Train/test splitting
- Feature preprocessing
- Model evaluation
- Accuracy, precision, recall, F1 and ROC-AUC
- Feature importance analysis

➡️ [View Machine Learning Project](./03_ML_Disease_Classification)
